3. Panduan Upload Source Code ke GitHub (Publik)

Langkah Upload via Android Studio (Paling Mudah):

  1. Buka project Jualinmarketplace di Android Studio.
  2. Klik menu VCS atau Git → Pilih Share Project on GitHub.
  3. Masukkan nama repository: Jualin-Marketplace.
  4. Pastikan opsi Make Private TIDAK dicentang agar repository bersifat Public.
  5. Klik Share / Push. Seluruh kode akan otomatis terunggah ke GitHub.
